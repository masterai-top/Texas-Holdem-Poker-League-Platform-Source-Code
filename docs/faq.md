# 常见问题

## 这是完整联盟平台源码吗？

当前公开内容主要是 C++/Tars 服务端模块。Unity/Cocos 客户端、H5、数据库初始化、完整后台和商业组件是否包含，需要以实际目录及授权说明为准。

## 如何下载？

在 [仓库首页](https://github.com/masterai-top/Texas-Holdem-Poker-League-Platform-Source-Code) 点击 **Code → Download ZIP**，或使用 README 中的 Git 克隆命令。

## 如何开始阅读？

先看 Login、Match、Global、GM 和 Order 的 `.tars`、`Server.cpp` 与 `ServantImp.cpp`，再查看 `roomlogic/` 和 `DBOperator.cpp`。

## 可以直接商业运营吗？

不能仅凭公开仓库判断。需要确认许可证、完整组件、构建状态、安全审计、第三方资源授权以及运营地区法律要求。

## 为什么不建议使用第三方品牌 Topic？

`ggpoker`、`pokerstars` 等品牌词可能造成来源误解、商标风险和错误搜索流量，不利于建立本项目自己的可信度。

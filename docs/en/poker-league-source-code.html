Texas Holdem Poker League Source Code

A structured product and engineering reference for a Texas Holdem league, club, points lobby and tournament system. It connects real interface material with the public C++/Tars modules without claiming that unseen client or operations code is included.

View repository

Games and product flow

Lobby and league

Players enter through the lobby, select a club, friend table or event, and continue to registration or matchmaking.

Tournament play

Product material covers classic Holdem, AOF, 6+ Short Deck, SNG and MTT. Rules depend on deployment configuration.

Service architecture

Login, match, rank, global, GM, order, database and room-logic entry points are visible in the repository.
